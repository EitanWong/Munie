# Changelog

## 0.1.0 — Unreleased

- Native iPhone/iPad local text capture, search, retrieval and confirmed deletion.
- Reusable Swift 6 storage package with atomic persistence and explicit failures.
- English and Simplified Chinese interface and README.
- Worktree workflow, pinned reference registry, automated checks and gated delivery configuration.

- Native multi-destination Xcode target for iOS/iPadOS, macOS, tvOS and visionOS; separate local-only watchOS app.
- Standard Swift Package layout, all-platform build checks and progressive Apple engineering/HIG agent documentation.

Remote AI execution, voice, Watch connectivity and glasses are not implemented. New platform hardware UX, tvOS/visionOS distribution artwork and signed delivery remain acceptance gates.
